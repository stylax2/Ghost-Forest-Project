# Vertical Decoupling and Community Disassembly

This repository contains the complete R code and datasets for the paper **'Vertical Decoupling and Community Disassembly: Projecting the Risk of ‘Ghost Forests’ in Quercus mongolica Communities'**.

## Contents
- **Code:** R scripts for data preparation, ensemble modeling, and ghost forest index analysis.
- **Data:**
  - `vege_table.xlsx`: Vegetation survey data used for diagnostic species analysis.
  - `present_total.xlsx`: Raw occurrence data.
  - `GBIF_Final_Dataset.csv`: Integrated occurrence data (NES + GBIF).

## Usage
The code assumes that the data files are located in the same directory as the scripts.
